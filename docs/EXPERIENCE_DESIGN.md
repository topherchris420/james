# Experience design: James

James is a desktop companion, not a game. StoryStack supplies a hierarchy of user expectations, not a pretext for scores, rewards, fictional autonomy, or unsolicited computer actions.

## StoryStack for a desktop companion

| Layer | Contract |
| --- | --- |
| Fantasy | Explore unfamiliar work with a capable assistant while keeping control of the model, context, and next action. |
| Action | Ask; choose what to share; inspect the answer and its source; follow up or decline a proposed action. |
| Economy | Attention, understanding, trust calibrated to evidence, and reversible choices. |
| World | The user's desktop, selected documents and screenshots, local model connection, and optional read-only lab view. |
| Story | A question becomes an investigation the user directs, not a task an autonomous agent silently completes. |

## First-use loop

1. **Explore:** choose a model, ask a question, or explicitly capture context.
2. **Influence:** decide which files, screenshot, or model to use; stop or change direction at any time.
3. **Discover:** inspect the answer, line references, and request evidence; verify important claims before relying on them.

## Boundaries

- No accidental screenshot capture or unapproved input. A guide's steps are suggestions, not observed proof of completion.
- A citation to supplied text proves only where text came from, not whether the claim follows from it.
- Keep local-first behavior and clear notices where a chosen model server or optional speech tool might contact external services.
- Never confuse an octopus illustration or companion animation with an autonomous agent's authority.
- Accessibility, reduced motion, and clear first-run failure states matter more than theatrical onboarding.

## Acceptance

Can a first-time user connect a model, ask one question, inspect what was sent and what came back, and understand how to deny or review a suggested action?
